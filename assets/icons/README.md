# Icons

## whatsapp-glyph-white.svg / whatsapp-glyph-green.svg

Offizielle WhatsApp-Bildmarke, unveraendert aus dem Meta Brand Resource Center:
<https://about.meta.com/brand/resources/whatsapp/whatsapp-brand/>

Paket: WhatsApp-Brand-Resource-Center.zip, Stand 2026
Entnommen aus `01_Glyph/01_Digital RGB/03_SVG/`.

Die Marke wird ausschliesslich in den von Meta geliefertenen Farbvarianten
verwendet (Weiss auf gruenem Grund) und nicht umgefaerbt, verzerrt oder
beschnitten. Die Dateien liegen hier als Referenz; im Markup stehen die
beiden Pfade inline, weil alle UI-Icons der Seite inline liegen - nur das
Firmenlogo nutzt das SVG-Sprite.

Ausnahme: In den Kontaktzeilen (.cr-icon) folgt die Marke der gemeinsamen
Einfaerbung der Zeile (currentColor, gelb), weil sie dort als Wegweiser-Icon
neben Telefon und E-Mail steht und nicht als Marken-Button auftritt.
